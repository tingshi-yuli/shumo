# v0.7-format-only 版本记录

本版本只修改论文格式，未修改正文事实、公式、结果、图表数据、参考文献内容或附录内容。

格式改动：

- 论文正文采用小四字号（`zihao=-4`），行距调为1.45倍；
- 题目采用三号黑体风格；
- 一级标题四号黑体居中；二、三级标题小四黑体左对齐；
- 正文保持宋体、首行缩进2字符；
- 页面保持A4，上下左右2.5厘米；
- 页脚保留页码，未增加页眉、眉线和目录；
- 图题统一小五字号，表格继续使用booktabs三线表；
- 浮动体数量限制和图文间距调整为每页尽量一张主图，避免连续堆图；
- 仅在导言区修改格式宏；从 `\\appendix` 开始的附录源文本逐字保持不变。

构建：

- 直接XeLaTeX/latexmk编译退出码0；
- 生成 `论文/build/main.pdf` 与 `格式修订论文.pdf`；
- 总页数71页，正文页数受当前源文件附录和行距影响，需在正式提交前按队伍最终附录组织再次确认；
- 论文源码与原 `resources/main.tex` 的 `\\appendix` 后内容完全一致。
